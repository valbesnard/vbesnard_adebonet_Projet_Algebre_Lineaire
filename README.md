# besnard_Projet_Algebre_Lineaire

## Pré-requis

### Git

- [Installation pour windows](https://git-scm.com/install/windows)
- [Installation pour Linux](https://git-scm.com/install/linux)

### Python

- [Installation pour windows](https://www.python.org/downloads/windows/)
- [Installation pour Linux](https://www.geeksforgeeks.org/python/how-to-install-python-on-linux/)

### Packages pythons

- [Jupyter Notebook](https://jupyter.org/install)

## Récupération du projet

Dans un terminal, se positionner dans le dossier où le projet doit être placer.

```sh
git clone https://github.com/valbesnard/besnard_Projet_Algebre_Lineaire.git
```

## Exécution du projet

1. Dans le dossier du projet, en terminal :

```sh
jupyter notebook
```

2. Dans le navigateur qui s'est ouvert, ouvrir : **Main.ipynb**
